# CashLens

> 给「一个人就是一家公司」的人，一个懂钱的 AI 财务团队。
> 面向一人公司与小微经营者的多智能体财务系统：把散落在微信、支付宝、票据、账单里的钱归拢成一束光，照见你下个月会不会缺钱，并在「这单接不接、报多少」的决策点给出有依据的建议。

## 它解决什么

- 收入像过山车——没人告诉你下个月能不能撑住
- 钱散在多个平台——月底对不上账是常态
- 报价靠感觉——拍脑袋定价，回头发现连成本都没覆盖

现有工具都不够：记账 App 只出报表；企业级软件一个人用不起；通用 AI 拿不到你的真实流水。

## 核心闭环

```
采集（说一句 / 拍一张 / 导一份）→ 财务状态引擎 → 决策建议 → 反馈回灌
```

## 三个核心创新

1. **财务状态引擎**——证据强度分级（流水 1.00 > 票据确认 0.85 > 主动记账 0.75 > 自报 0.10 > 系统推测 0.00），状态可升可降、会过期、能从事件账本重建。记了一笔 ≠ 现金流健康。
2. **CashPulse 现金流预测**——基于历史节奏输出未来 30/90 天现金流**区间**（90% 置信带），可信度低时如实标注「现金流不明」，数据不足时如实标注不可信，不做假装精确的点预测。
3. **假设检验闭环**——每次决策记录当初假设，账本自动检验偏差（如回款周期 3 天 vs 实际 3 周），下次报价自动参考。

> 当前阶段：状态引擎与 CashPulse 最小版已实现（真实计算）；决策引擎完整闭环与登录型前端为下一阶段。本仓库按「原型 / 早期验证」口径对外呈现（证据见 `docs/` 实弹记录，含如实披露的缺陷）。

## 多智能体架构

不是 N 个机器人常驻，而是 **1 个编排引擎按需激活 N 个 Markdown SKILL**（方法论即文件，可自加），MCP 协议统一接入工具。SKILL 口径：方法论规划 33 个 · MVP 清单 8 个 · 仓库已落地 3 个示例（记账 accounting / 接单决策 order-decision / 现金流预测 cashflow-forecast），其余标注 Phase 2/3。LLM 层为 OpenAI 兼容统一网关，服务商可插拔。

## 已实现能力（2026-09 状态）

- **对话记账**：说一句就记（语音/文字），支持中文金额（三千 / 二九九 / 三百五）、多笔拆分、报销垫付语义；
- **多轮自由对话**：接入 LLM API 后支持连续追问与跨上下文（「那笔是哪天的？」「上个月花了多少」），未配置时自动回退规则兜底（本地零成本可用）；
- **识别 → 确认 → 入账**：记账先生成待确认草稿，由用户确认/拒绝后才写入账本；
- **真数据查询**：最近一笔收入/支出、本月支出分类汇总、现金流 30 天 90% 区间——数值全部由本地账本与状态引擎计算，LLM 不参与编造数值；
- **事件账本 + 状态引擎最小版**：追加式 jsonl 账本、dedupe 幂等去重、SQLite 可重建投影、asOf 读取时计算（证据分级/健康度/状态标签）；
- **创意阐述页**：三种用户场景、证据脚注（出处可溯源）、实弹验证记录、开发路线页（见 `docs/`）。

## 仓库概览

| 路径 | 职责 |
|:--|:--|
| `backend/` | FastAPI 后端：事件账本、状态引擎、查询工具、对话 API（规则 + LLM 双通道） |
| `engine/` | 编排引擎工作区：SKILL 方法论、子代理定义、MCP 工具服务器 |
| `frontend/` | 真数据对话式财务工作台（记账对话 + 现金流/状态面板） |
| `docs/` | 网页版创意阐述页（GitHub Pages 发布，含实弹证据与出处） |
| `scripts/` | 工具脚本（票据批量识别、语音识别客户端、PDF 渲染等） |
| `samples/` | 合成演示样本（可入库；真实用户数据一律隔离） |
| `tests/` | 后端单测（pytest）与 demo 行为回归（Node，直接加载真实页面脚本断言） |

## 快速开始（原型阶段）

```bash
# 0) 配置环境（可选：不填 LLM API Key 时对话走规则兜底）
cp .env.example .env

# 1) 后端 API（事件账本 / 状态引擎 / 对话），在 backend 目录内：
python3 -m uvicorn app.main:app

# 2) 前端工作台（另开一个终端），在 frontend 目录内：
pnpm install && pnpm dev
# 打开终端提示的本地地址即可对话记账 / 查现金流

# 3) 网页版创意阐述页：直接用浏览器打开 docs/index.html

# 4) 票据识别冒烟（识别 samples/ 合成样本）
python3 scripts/batch_recognize.py samples/

# 5) 测试
python3 -m pytest tests/            # 后端单测
node tests/demo_behavior.test.mjs   # demo 行为回归
```

> 语音识别依赖本机 ASR 工具与模型：通过环境变量 `ASR_CLI` / `ASR_MODEL` 指向本机可执行文件与模型（仓库不内置、不记录路径）。
> 启动后端 API 前请先在仓库根目录执行 `cp .env.example .env`；`.env` 已被 `.gitignore` 拦截，永不入库。

## 安全与隐私

- `.env`（密钥）、`data/`（本地账本/状态库/待确认草稿）、用户上传数据目录一律不入库（见 `.gitignore`）
- 账本与金额计算始终在本地磁盘完成；金额与现金流数值不依赖任何外部服务
- 启用云端 LLM 时，仅对话文本会发送给所选 LLM 服务商（页面上明示）；关闭 LLM 即全本地
- 网页演示在浏览器本地完成，不采集任何数据
- 纪律：AI 自报不可信（R38）——本仓库每个对外声称都尽量带真实实测证据或如实标注"示意/规划"
