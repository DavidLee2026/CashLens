# CashLens

> 给「一个人就是一家公司」的人，一个懂钱的 AI 财务团队。
> 面向一人公司与小微经营者的多智能体财务系统：把散落在微信、支付宝、票据、账单里的钱归拢成一束光，照见你下个月会不会缺钱，并在「这单接不接、报多少」的决策点给出有依据的建议。

## 它解决什么

- 收入像过山车——没人告诉你下个月能不能撑住
- 钱散在多个平台——月底对不上账是常态
- 报价靠感觉——拍脑袋定价，回头发现连成本都没覆盖

现有工具都不够：记账 App 只出报表；企业级软件一个人用不起；通用 AI 拿不到你的真实流水。

## 核心闭环

```
采集（说一句 / 拍一张 / 导一份）→ 财务状态引擎 → 决策建议 → 反馈回灌
```

## 三个核心创新

1. **财务状态引擎**——证据强度分级（流水 1.00 > 票据确认 0.85 > 主动记账 0.75 > 自报 0.10 > 系统推测 0.00），状态可升可降、会过期、能从事件账本重建。记了一笔 ≠ 现金流健康。
2. **CashPulse 现金流预测**——基于历史节奏输出未来 30/90 天现金流**区间**（90% 置信带），可信度低时如实标注「现金流不明」，不做假装精确的点预测。
3. **假设检验闭环**——每次决策记录当初假设，账本自动检验偏差（如回款周期 3 天 vs 实际 3 周），下次报价自动参考。

## 多智能体架构

不是 N 个机器人常驻，而是 **1 个编排引擎按需激活 N 个 Markdown SKILL**（方法论即文件，可自加），MCP 协议统一接入工具。MVP 实弹 8 个 SKILL，其余标注 Phase 2/3。LLM 层为 OpenAI 兼容统一网关，厂商可插拔。

## 仓库概览

| 路径 | 职责 |
|:--|:--|
| `backend/` | FastAPI 后端：数据、认证、与引擎通信的网关 |
| `engine/` | 编排引擎工作区：SKILL 方法论、子代理、MCP 工具服务器 |
| `frontend/` | 前端（原型开发中；当前演示见 `docs/`） |
| `docs/` | 网页版项目介绍（GitHub Pages 发布） |
| `scripts/` | 工具脚本（票据批量识别、PDF 渲染等） |
| `samples/` | 合成演示样本（可入库；真实用户数据一律隔离） |

## 快速开始（原型阶段）

```bash
# 1. 配置环境（复制模板并填入你的 LLM API Key）
cp .env.example .env

# 2. 票据识别冒烟（批量识别 samples/ 下的合成样本）
python3 scripts/batch_recognize.py samples/

# 3. 网页版项目介绍 + 交互演示（浏览器直接打开，纯本地）
open docs/index.html
```

> 注：当前为原型阶段，采集模块已实弹验证（真实数电发票识别），状态引擎 / 决策引擎闭环开发中。

## 安全与隐私

- `.env`（密钥）与用户上传数据目录一律不入库（见 `.gitignore`）
- 数据默认留在本地磁盘
- 网页演示在浏览器本地完成，不采集任何数据
