“一个人就是一家公司”的人，钱没人管

独立开发者、设计师、小店主，收入像天气，账散在五个 App 和一抽屉发票里。到了月底，只剩一句“这个月到底赚没赚”，没人答得上来。

技术层财务状态引擎把散落的收支变成可计算的财务状态与 30/90 天现金流区间，而不是一张事后才看得见的报表。

问题从来不是不会记账，而是记完了也没人告诉你下一步怎么办。多数工具停在记账和报表，管不到“决策”这一层。

WHAT · 产品

一层内核，三层能力

你不用学记账，也不用懂财务。说一句话、拍一张票、导一份账单，剩下的三步我们替你走：先把钱归拢，再把账照见，最后在决策点上给一句话。

技术层事件账本（不可变）→ 财务状态引擎 → CashPulse 现金流区间预测 → 接单报价决策引擎，四层串成一条链路，每一层的结果都能回灌到上一层。

对话是唯一入口：说一句（语音）、拍一张票据、导一份账单，都能记一笔。背后是三件事，归拢、照见、建议。

归拢 · 采集

说一句，就是记一笔

1. 说一句：语音或文字记账（产品主打入口，分期推进），本地实弹转写已跑通，云端语音识别按复赛节奏接入；2. 拍一张：票据或截图，云端 LLM 视觉 API 识别，真实数电发票实弹已过；3. 导一份：微信、支付宝官方账单 CSV，或一张张项目工时 Excel，批量导入。所有数据汇入一本不可变的“事件账本”，官方导出才是正道，不做不稳定的平台自动同步。账单解析已实弹工时表解析端已实装 · 页面入口规划中

照见 · 理解

不看记了多少笔，看钱撑不撑得住

把流水变成财务画像 + 30/90 天现金流区间预测 + 待唤醒动作。状态可升可降、会过期、能从账本重建，所以“记了一笔”不等于“现金流健康”。

建议 · 决策

在决策点上，给一句有依据的话

这单接不接、报多少，结合现金垫底、历史回款周期、时间成本给出报价区间与理由；缺口提前 30 天预警，把“怕断粮”变成“提前备粮”。

产品最核心受众

他们的钱，长这样

  • 收入是脉冲式：一单几万、一歇几周，进账没有节奏，月初不知道自己月底有多少。

INNOVATION · 核心创新

三个创新，指向同一个差异：
财务决策层的“可信”

它说的数字，你敢不敢照着做决定？下面三件事，就是让这句话站得住的全部理由。

技术层财务状态引擎（证据强度分级、防幻觉）、CashPulse（90% 置信区间预测、样本不足如实标注）、假设检验闭环（决策假设回灌账本）。

不是又一个记账工具，是把你散落的钱变成能支撑决策的证据。

1. 财务状态引擎
证据驱动 · 防幻觉

每次收支按证据强度分级入账，只有真实证据才能改变财务状态，系统不猜测你的健康度。

流水自动到账1.00
票据识别 + 人工确认0.85
自然语言主动记账0.75
用户自报“没问题”0.10
系统推测0.00

2. CashPulse 预测
区间预测 · 绝不玄学

基于你的历史收入节奏，输出未来 30/90 天现金流区间（90% 区间按历史波动以正态近似估算，样本不足时如实标注不可信），可信度低时明示“现金流不明”，而不是给一个假装精确的数字。

下月预计余额¥3,200 ± 4,600
缺口预警第 18 天 预计 ¥-2,400
依据过去 3 个月收入节奏

3. 假设检验闭环
记忆体 · 越用越准规划中

每次决策记录“当初假设”，账本自动检验偏差。报价时以为 3 天回款、实际 3 周，偏差会被标记，下次报价自动参考。

当初假设回款 3 天
实际检验3 周
下次报价回款周期已计入现金垫底

一次分析，持续陪伴。这是“财务记忆体”的复利，也是与记账工具的分水岭。
