# 记账 SKILL

## 职责

把用户的一句话收支描述，转成结构化交易记录（事件账本的一条输入）。

## 输入

用户的中文自然语言描述，例如：
- 「昨天微信收了 3000 尾款」
- 「买了杯咖啡 45」
- 「拼多多退货退了 89」

## 输出格式

只输出以下 JSON（不要多余解释）：

```json
{
  "type": "income|expense",
  "amount": 数字,
  "category": "分类名",
  "channel": "渠道(可选)",
  "note": "备注"
}
```

## 规则

1. 金额从描述中提取，保留两位小数
2. 分类映射：收入 → 接单 / 工资 / 退款 / 其他；支出 → 餐饮 / 交通 / 购物 / 房租 / 其他
3. 无法判断收支类型时，反问用户确认，不猜测
4. 证据类型标为 `self_report`（用户自报，证据权重 0.10）
5. 只输出 JSON，不做额外解释

## 示例

用户说「昨天微信收了 3000 尾款」→

```json
{"type": "income", "amount": 3000.00, "category": "接单", "channel": "微信", "note": "尾款", "evidence": "self_report"}
```
